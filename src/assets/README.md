# NSP Box icons

`icons/app.png` is the user-provided NSP Box app design, with its white exterior
removed using the built-in image generation tool. `app.ico` is a multi-resolution
Windows encoding of this same design. The other 21 PNGs are separately generated
UI concepts in the navy / ice-blue / azure palette, created with image_gen.

Game, DLC, emulator patch, artwork and patch operations have distinct symbols.
The images are bundled locally, with no runtime download. Raster cutout edges
may still show small generation artifacts; these assets are included in the experimental release. Native checkbox marks and the status spinner remain code-drawn.

The app logo belongs to this project. No Nintendo logo or game artwork is used
for the application icon.
